LLMs

How modern language systems fit together

Large language models are one layer in a broader application stack. Keeping the pieces separate makes design decisions cleaner.

Open LLM Learning Guide Browse Learning Guides

Model

The base model provides pattern prediction over tokens. Its strengths and limits are shaped by training data, architecture, context length, and alignment work.

Prompt

The prompt supplies task framing, constraints, examples, and current context. Good prompting improves consistency, but it does not replace missing knowledge.

System

Retrieval, tools, memory, guardrails, and evaluation sit around the model. Most production quality comes from this system layer.

Key concepts

  • Tokens: the text units the model consumes and generates.
  • Context window: how much input the model can consider at once.
  • Embeddings: vector representations used for semantic search.
  • RAG: retrieval-augmented generation for grounding responses.
  • Tools: external functions or APIs the model can call.

Practical failure modes

  • Hallucinated facts when the model lacks grounding.
  • Prompt brittleness across small phrasing changes.
  • Context overflow that drops important instructions.
  • Unreliable tool selection or bad tool arguments.
  • Evaluation gaps that hide regressions.

Useful mental model

Treat the model like a probabilistic reasoning engine, not a source of guaranteed truth. When accuracy matters, give it retrieval, tool access, explicit checks, and task-specific evaluation.

Better prompt phrasing helps. Better system design helps more.
