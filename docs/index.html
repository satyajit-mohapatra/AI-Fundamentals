Publishing

GitHub Pages setup

  1. Push the repo to GitHub.
  2. Open repository Settings and then Pages.
  3. Select Deploy from a branch.
  4. Choose the default branch and the /docs folder.
  5. Save. GitHub will publish docs/index.html.

Operating Rule

Keep the repo light

Prefer notes, diagrams, code examples, and links. Avoid checking in large generated outputs, local dependency trees, or bulky binary exports.

That keeps the site fast to load, easier to review in pull requests, and easier to maintain over time.
