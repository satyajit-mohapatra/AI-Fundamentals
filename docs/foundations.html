Foundations

Base concepts before model hype

This page keeps the first layer simple: what a model is, how data is used, and how to tell whether a system is actually working.

Core pipeline

  1. Define the task clearly.
  2. Collect or prepare representative data.
  3. Train or select a model.
  4. Run inference on new inputs.
  5. Evaluate outputs against the real goal.

Essential distinctions

  • AI: the broad field of building intelligent behavior.
  • ML: systems that learn patterns from data.
  • Deep learning: ML with layered neural networks.
  • Inference: using a trained model to produce an output.

Evaluation matters more than demos

A model that looks impressive in a small demo can still fail in production. Evaluation should match the actual use case: accuracy, precision and recall, latency, cost, robustness, and human acceptability all matter depending on the task.

If the metric is detached from the real task, the system will optimize the wrong thing.

Data quality checklist

  • Is the data representative of real inputs?
  • Are labels correct and consistent?
  • Is there leakage from training into evaluation?
  • Are edge cases present or missing?
