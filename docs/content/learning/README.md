# Learning Guides

These guides expand the short summary pages into fuller study material.

Use them when the summary page is too compressed and you want the reasoning, examples, tradeoffs, and practical checks behind each point.

## Guides

- `foundations-learning-guide.md`: expands the points from the Foundations page into a fuller learning document.
- `llm-learning-guide.md`: expands the points from the LLMs page into a fuller learning document.

## How to use these guides

1. Read the short summary page first so you know the map.
2. Open the matching learning guide to study the concepts in more depth.
3. Pause after each major section and write your own example.
4. Convert the concepts into repo work, prompts, evaluation checks, or system design notes.

## Study rule

Do not stop at definitions. For each concept, ask:

- What problem is this concept solving?
- What breaks when the concept is misunderstood?
- What would I inspect in a real codebase or AI system to verify it?
