# AI Coding Course Video Scripts

These scripts expand the course outlines into recordable lesson plans. Each lesson is designed for an 8-15 minute video and includes:

- **Recording target:** estimated runtime and production style
- **Presenter script:** what to say, organized by time
- **Screen direction:** what to show while speaking
- **On-screen text:** short text for slides, lower-thirds, or callouts
- **Demo steps:** concrete actions to record
- **Exercise prompt:** what the learner should do after watching
- **Closing recap:** final lines to end the video

## Recording Notes

- Keep terminal text large enough to read.
- Pause after each command so output is visible.
- When showing agent output, review the diff or evidence instead of only reading the agent summary.
- For every lesson, end with a learner action. The course should feel like practice, not passive lecture.
- If a demo depends on a specific repo, use a small toy repo first, then explain how the same pattern applies to the course repo.
- Use CourseForge as the default sample app whenever a lesson needs a concrete feature, task, issue, PRD, tracer bullet, or capstone example.
- Keep tool references neutral. Say "agent harness" by default, then optionally show how the same step looks in a terminal-based tool, CLI agent, IDE agent, hosted agent app, or another supported environment.

## Running Example

CourseForge is a production-style course creation workspace. Use it to demonstrate:

- Course, module, and lesson organization
- Lesson script drafting and review
- AI writing assistant modes
- Publishing task tracking
- GitHub Issues and Kanban workflows
- HITL and AFK task boundaries
- Architecture review and capstone handoff
